\# SuperRadar



> 开放毫米波感知技术社区｜Open mmWave Sensing Community



SuperRadar 是由承泰科技发起并长期支持的开放毫米波感知技术社区，聚焦毫米波雷达、AI 感知、多传感器融合、机器人、低空经济、智能交通、工业安全与高校科研等方向。



我们希望通过开放硬件、开放数据、开发工具、技术文档、示例工程与真实场景实践，降低毫米波雷达技术的研究与应用门槛，帮助开发者、科研团队和产业伙伴更快进入毫米波感知的底层数据链路，共同探索智能感知的更多可能性。



\---



\## 我们关注什么



SuperRadar 关注毫米波雷达从底层数据到场景应用的完整链路，包括但不限于：



\* 毫米波雷达硬件与开发套件

\* ADC 原始数据采集与处理

\* 点云数据输出、可视化与分析

\* 雷达信号处理算法

\* 目标检测、跟踪与轨迹分析

\* 多传感器融合感知

\* 机器人、低空、交通、园区与工业场景应用

\* 高校教学、科研实验与社区共创

\## 当前项目



\### CTSAI-A100 社区版毫米波雷达



CTSAI-A100 社区版是 SuperRadar 社区面向科研单位、算法团队与技术开发者开放的毫米波感知硬件，支持点云数据输出与 ADC 数据采集，适用于毫米波雷达信号处理、点云算法开发、目标检测、轨迹分析、多传感器融合与场景数据采集等研究方向。



\* 项目仓库：\[CTSAI-A100](https://github.com/SuperRadar/ctsai-a100)

\* 快速开始：\[Quick Start](https://github.com/SuperRadar/ctsai-a100/blob/main/docs/quick-start.md)

\* 上位机使用：\[RadarTools Guide](https://github.com/SuperRadar/ctsai-a100/blob/main/docs/radartools-guide.md)

\* ADC 数据采集：\[ADC Capture](https://github.com/SuperRadar/ctsai-a100/blob/main/docs/adc-capture.md)

\* Python 可视化：\[Python Visualization](https://github.com/SuperRadar/ctsai-a100/blob/main/docs/python-visualization.md)

\* 下线标定：\[Calibration](https://github.com/SuperRadar/ctsai-a100/blob/main/docs/calibration.md)

\## 推荐从这里开始



如果你是第一次了解 SuperRadar，可以按以下路径开始：



1\. 阅读 \[SuperRadar 官网](https://superradar.cn)，了解社区定位、硬件资源和参与方式。

2\. 进入 \[CTSAI-A100 项目仓库](https://github.com/SuperRadar/ctsai-a100)，查看当前开放硬件项目。

3\. 按照 \[快速开始文档](https://github.com/SuperRadar/ctsai-a100/blob/main/docs/quick-start.md) 完成硬件连接、驱动安装和上位机运行。

4\. 使用示例数据运行 Python 或 MATLAB 示例，理解点云数据与 ADC 数据处理流程。

5\. 通过 Issue、Discussion 或 Pull Request 参与文档、代码、数据和场景共建。

\## 社区方向



SuperRadar 关注的不只是单一硬件，而是毫米波感知技术在更多真实场景中的开放探索。



我们希望与社区一起推进：



\* 开放毫米波雷达硬件资源

\* 建立可复用的数据采集与处理流程

\* 沉淀雷达信号处理和点云算法示例

\* 推动多传感器融合研究

\* 支持高校科研与教学实验

\* 探索机器人、低空、交通、园区和工业场景应用

\* 构建开放、协作、可持续的毫米波感知生态

\## About SuperRadar



SuperRadar is an open mmWave sensing community focused on radar hardware, ADC data, point cloud processing, signal processing, multi-sensor fusion, robotics, intelligent transportation, low-altitude sensing, industrial safety, and research applications.



We welcome developers, researchers, universities, and industry partners to explore open sensing technologies together.
